# Фронт 2: подключение команды

Ветка фронта 2 содержит только свой UI, контроллер, сеть и адаптеры.
Графику создаёт модуль `world` фронта 1. `WorldConnection` находит его через
опциональный Vite import, вызывает `await world.init()` во время интро,
подключает события сервера и запускает один цикл:

```js
gameplay.update(dt, elapsedSeconds);
world.frame(dt);
```

До слияния фронта 1 приложение работает как UI; `?offline=1` всегда оставляет
только проверку UI. Новых моделей, renderer или сцены у фронта 2 нет.

## Контроллер

Позиция `p` — ноги. Глаза на 1,6 м выше. `r` — yaw камеры: 0 смотрит вдоль -Z,
то есть на нос. Появление учитывает `scene.r`; `pos_correct` немедленно меняет
позицию и yaw. Движение посылается максимум 15 раз/с при изменениях.

Капсула совместима с фронтом 1: `{start:Vector3,end:Vector3,radius:0.35}`.
За кадр четыре подшага с гравитацией, результат collide — `{onGround,delta}`.
Прыжка нет. В night_story — только поворот головы ±100°.

## Мир

- `chunk ship 0,0` передаётся в `world.loadLayout()`; `interact` адаптируется в
  `interactables`. Второго кеша чанков у фронта 2 нет.
- `entity.state.holder` превращается в `visible:false`; часы читают emptyAt.
- `players.upsert/snapshot/remove/say` получают реальные сообщения, собственный
  игрок отфильтрован из snapshots. Облако чата держится 4 с.
- F3 читает `world.stats().calls` и `chunks`, без выдуманных процентов или пинга.
- Остров/чанковый LRU пока не реализован модулем мира; это работа фронта 1.

Экспорты main.js: `attachWorld`, `gameEvents`, `sendGameMessage`,
`getPlayerState`, `playVoiceLine`. Для мира, который подключается извне,
attachWorld возвращает `{update,dispose}`. Не запускать второй цикл поверх
автоматического `WorldConnection`.

## Бэк 1

Используются auth_ok.scene, pos_correct, trade_state, scene.r. Код 4002
останавливает reconnect, 4001 возвращает к логину. Регистр логина сохраняется
при отправке; сервер сравнивает имена без учёта регистра.

Ответ астролябии: `minigame {game:'astrolabe',result:{angle,answer:33}}`.
Задание и инвентарь меняются только по ответам сервера. Шаг задания берётся
из `quest.text`, прогресс подзадачи — count/need. Для торговца цены и кошелёк
читаются из trade_state; решение о покупке остаётся у сервера.

## Бэк 2

Имена, предметы, задания и готовые реплики читаются из общих content JSON.
NPC ID не переименовываются. Для scripted NPC нет поля вопроса: реплики из
lines.json, MP3 по ID из /audio/vo/manifest.json. LLM NPC отвечают по WebSocket.
Готовые серверные события npc_say с line проигрываются и вне панели диалога.

intro/night_story читаются опционально после слияния ai. Таймлайн использует
длительности манифеста и startAt; при входе в середине сцены выбирается текущая
реплика и смещение. Нужны согласованные часы ноутбуков: отдельного clock-sync
в протоколе сейчас нет. Временное интро — текстовые панели без JPG.

События voice {playing} и narrative_event {type,id,pos,dur} предназначены
владельцу мирового звука (по последнему распределению — бэк 2).
Для включения звука при первом клике есть audio_unlock.
