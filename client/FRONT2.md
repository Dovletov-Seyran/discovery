# Фронт 2

Рабочая копия репозитория Dovletov-Seyran/discovery, ветка `codex/front2-skeleton`.
Основа: main `0684580`. Изменения только в `client/`.

## Запуск

Из корня репозитория, Node.js 24+:

```bash
npm install
npm run dev
```

- http://localhost:5173/ — реальная регистрация, вход и лобби через сервер команды.
- http://localhost:5173/?offline=1 — проверка только UI, без сервера и 3D.

На этом ноутбуке без системного Node.js: `./client/start-local.sh`.
Скачанный Node находится за пределами репозитория, в рабочей папке Codex.

В проверке UI: имя → роль → «Готов». Кнопки внизу открывают карточку предмета,
диалог, астролябию и задание. Тексты NPC — фиксированные тестовые данные.
Tab — инвентарь, Enter — чат, Esc — меню.

## Границы работы

В src/net — авторизованный WebSocket и тестовый адаптер. В src/game — ввод,
контроллер и raycast. В src/ui — экраны, HTML-оверлеи, тексты и стили.

Здесь нет сцены, рендера, корабля, моделей, света, воды, NPC-моделей или генерации
мира. Колумб в интерфейсе — только имя собеседника в панели диалога.
Roboto Condensed с кириллицей лежит локально в public/fonts вместе с OFL.
Это открытый шрифт для стиля меню в духе Skyrim, не оригинальный шрифт игры.

тестового пользователя в БД сервера; запускать на разработческом сервере.

Подключение мира: src/game/INTEGRATION.md.

## Локальная особенность сборки

На этом ноутбуке нативный Rollup завершается с Illegal instruction. Для проверки
установлен @rollup/wasm-node в рабочей папке Codex и заменена только локальная
ссылка node_modules/rollup. package.json и package-lock.json команды не менялись.
После npm ci на этом же ноутбуке локальную замену потребуется восстановить.

Уточнения команды: добавлены проигрыватель готовых MP3 по ID, таймлайн
интро/ночной истории, короткие субтитры и продолжение с нужного смещения.
Файлы AI находятся в origin/ai, их ещё нет в main этой копии. Подготовлен
потребитель данных; сами чужие аудиофайлы и content не копировались в изменения
фронта 2. До слияния ai интро показывает только заголовок и пропуск.
Панели с иллюстрациями и окончательная связь с world.frame/loadLayout остаются
на следующий этап после появления модуля мира в общем репозитории.

Обновление: шрифты Cormorant Garamond и Marck Script (кириллица, локальные OFL).
Стиль по присланному образцу: старинные засечки и рукописные акценты.
Адаптер мира теперь использует фактическое API опубликованной ветки фронта 1.
Сводка межкомандных стыков — TEAM_INTEGRATION.md.
