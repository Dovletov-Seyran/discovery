Roboto Condensed — local variable font with Cyrillic. Used as an open alternative
for the narrow, restrained typography of Skyrim's menus; not Bethesda's font.
Source: https://github.com/google/fonts/tree/main/ofl/robotocondensed
License: SIL Open Font License 1.1, see OFL.txt.

Cormorant Garamond (upright and italic) — old serif lettering and readable
Cyrillic. Marck Script — pen lettering for title accents and NPC names.
Both are local SIL OFL fonts; see Cormorant-OFL.txt and Marck-OFL.txt.
Sources: google/fonts, ofl/cormorantgaramond and ofl/marckscript.
Roboto Condensed is retained as a technical fallback, not the main UI face.
