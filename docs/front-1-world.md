# Фронт 1 — мир, графика, аватары, 3D-катсцены

**Зона ответственности:** `client/src/world/`, ассеты в `client/public/models`, `textures`. **Звук целиком у Бэка 2.**
**Общие документы:** [README.md](README.md), [content-part1.md](content-part1.md).

**Цель:** красиво и стабильно 60 FPS на трёх ноутбуках (Mac, Windows, Linux) в Chrome. Стиль — **полуреализм**: PBR-материалы с процедурными текстурами дерева и парусины, небо `Sky` с облаками, вода `Water` с отражением, мягкие тени, цветокоррекция. Люди пока простые фигуры (замена на модели — F1.6).

---

## Что ты отдаёшь Фронту 2 (API модуля `world`)

```js
world.init(canvas, quality)            // рендерер, сцена, камера
world.camera                           // камера от первого лица (её двигает Фронт 2)
world.setZone('ship' | 'canary')       // показать нужную зону
world.setTimeOfDay(t)                  // 0..1, плавно
world.collide(capsule)                 // разрешение коллизий для контроллера
world.groundHeight(x, z)               // высота пола/рельефа
world.interactables                    // массив Object3D с userData {id, kind, label}
world.players.upsert(id, {name, role}) // удалённые игроки
world.players.snapshot(list, time)     // данные из snapshot
world.chunks.update(playerPos)         // менеджер чанков (запросы через net)
world.cutscene.play(id, startAt)       // 3D-катсцены → Promise
world.setQuality('ultra' | 'high' | 'low')
// добавлено при реализации:
world.frame(dt)                        // обновить и нарисовать кадр (из игрового цикла Фронта 2)
world.layout.spawns / world.layout.seats // точки появления ролей и места у фонаря ({ p, r })
world.entity(id), world.setEntityState(id, { visible, fill }) // ручное управление объектом
world.applyEntity(id, state)           // сообщение `entity` от сервера: { holder } прячет предмет, { emptyAt } ведёт песочные часы
// чанки (вызывает Фронт 2, подробно — в начале client/src/world/chunks.js):
world.chunks.setSender((msg) => socket.send(msg)) // через него уходят chunk_req / chunk_drop
world.chunks.setWorldMeta(authOk.world)          // { zones, totalChunks, totalBytes, cacheLimit }
world.chunks.receive(zone, key, data)            // на `chunk`; корабль — это чанк ship 0,0
world.chunks.denied(zone, key, reason)           // на `chunk_denied`
world.players.say(id, text)            // облачко чата над игроком
world.stats()                          // { fps, calls, triangles, quality, tod, chunks } для F3
```

**Соглашения:**
- `await world.init(...)`: текстуры генерируются в Web Worker (~1,5 с на Apple M1), удобно запускать во время интро.
- Пространство зоны `ship`: главная палуба `y = 0`, ют `y = 1.95`, бак `y = 1.6`, нос в сторону `−z`, правый борт `+x`.
- Поворот персонажа `r` (в `move`/`snapshot` и в `ship_layout.json`) — yaw как у камеры: `0` = смотрит на нос (`−z`).
- Капсула для `collide`: `{ start, end, radius }` — центры нижней и верхней сфер в мировых координатах; функция выталкивает капсулу и возвращает `{ onGround, delta }`.
- Качка — наклон окружения (небо, море, свет), а не корабля: координаты игроков и коллайдер неподвижны.
- Пространство зоны `canary`: координаты острова из `canary_layout.json`, уровень моря `y = 0`. Качки нет, тень идёт за игроком, все три корабля стоят на якоре в бухте.
- `world.interactables` всегда отдаёт объекты текущей зоны (на острове — только видимых чанков).
- Без сервера мир смотрится на `client/world-dev.html` (`npm run dev` в `client/`), остров — `?zone=canary`, клавиша Z переключает зоны. Чанки там отдаёт `dev/fakeServer.js`: копия генератора Бэка 1, источник правды — сервер.

Начни с заглушек: сначала договорись о сигнатурах, потом наполняй.

## F1.1 Рендерер и пресеты качества (0,5–1,5 ч)

- `WebGLRenderer({ antialias })`, `outputColorSpace = SRGBColorSpace`. На `low`/`high` нет постобработки вообще: цветокоррекция (насыщенность, контраст, тёплый оттенок) встроена в тон-маппинг (`CustomToneMapping` = ACES + грейд), сглаживание — собственный MSAA канваса. `EffectComposer` только на `ultra`: один пустой композер с MSAA в half-float буфере стоил ~13 мс на полноэкранном Retina.
- Пресеты:

| | ultra | high | low |
|---|---|---|---|
| pixelRatio | `min(devicePixelRatio, 1.5)` | `min(devicePixelRatio, 1.25)` | 1 |
| Сглаживание | SMAA | MSAA канваса | MSAA канваса, если игра стартовала не на `low` |
| Тени | 1 направленный свет, карта 2048 (PCF) | так же | выкл. |
| Вода | `Water`, отражение 512 (без мелкого реквизита) | так же | отражение 256 |
| Постобработка | GTAO в половинном разрешении, bloom фонарей, виньетка | нет | нет |
| Текстуры | 1024 | 1024 | 512 (если выбран при `init`) |

- Замер на Mac с Apple M1, холст 1512×982 CSS-пикселей с Retina (как Chrome во весь экран), мс на кадр без ожидания vsync:

| | день | ночь |
|---|---|---|
| low | 2,2 | 2,6 |
| high | 3,8 | 5 |
| ultra | 14 | 18 |

  До переделки `high` стоил 18 мс, `ultra` — 32 мс.
- **Проверка на Windows и Linux:** на ноутбуке открыть `http://<IP Mac>:5173/world-dev.html?bench` (на Mac в `client/`: `npm run dev`), развернуть окно на весь экран, подождать ~1,5 мин и прислать таблицу. В ней FPS, p95, стоимость кадра и рекомендуемый пресет; если браузер рисует без видеокарты, страница предупредит.
- **Автовыбор:** первые 3 с меряем FPS; если < 45 — переключаемся на `low`. Ручной переключатель — в настройках (UI у Фронта 2).
- Счётчик FPS и draw calls по F3 (вместе со счётчиком чанков).

**Бюджет на кадр:** ≤ 150 draw calls, ≤ 400 тыс. треугольников, текстуры ≤ 1024 px.

## F1.2 Вода и небо (0,5–1,5 ч)

- Вода: `Water` из `three/examples/jsm/objects/Water.js`, текстура `waternormals.jpg`. Цвет моря тёплый бирюзово-синий, днём `distortionScale ≈ 3`, ночью темнее и спокойнее (штиль: волнение почти 0).
- Небо: `Sky` из `three/examples/jsm/objects/Sky.js`; `PMREMGenerator` раз в несколько секунд для окружения (не каждый кадр).
- Корабль стоит на месте, а «движение» создаём скоростью текстуры воды и лёгкой пеной у бортов. В штиль скорость = 0.

## F1.3 Время суток (5–6,5 ч)

`setTimeOfDay(t)` плавно интерполирует набор параметров между ключами:

| t | Момент | Солнце | Цвет света | Туман |
|---|---|---|---|---|
| 0.40 | День | высоко | тёплый белый | лёгкий голубоватый |
| 0.72 | Закат | у горизонта | оранжево-розовый | золотистый |
| 0.85 | Сумерки | под горизонтом | фиолетовый | плотнее |
| 0.95 | Ночь (туман) | — , луна за туманом | холодный синий, 0.15 | **плотный серо-синий (FogExp2)** |

- Фонари: 2–4 `PointLight` без теней, тёплые, с мерцанием (шум по интенсивности). Ночью фонарь у рассказчика — главный источник света.
- Небо `Sky` ночью почти чёрное, плюс простые звёзды (Points), которые прячутся в тумане.

## F1.4 Корабль (1,5–3 ч)

- Модель: готовая GLB (корабль из Kenney Pirate Kit или подходящий CC0/CC-BY с Sketchfab/Poly Pizza — **записать лицензию в `docs/credits.md`**). Важнее, чтобы она была цельной и лёгкой, чем исторически точной.
- Оптимизация: `npx @gltf-transform/cli optimize in.glb out.glb --texture-compress webp`.
- **Коллайдер:** отдельная упрощённая невидимая геометрия палубы и бортов. Коллизии — `three-mesh-bvh` (капсула игрока против BVH коллайдера, как в примере `characterMovement` из репозитория three-mesh-bvh).
- Если у модели нет трюма, все предметы и NPC ставим на палубу (см. планировку в content-part1.md).
- **Расстановка:** `content/ship_layout.json` в формате сервера: `spawns`, `seats`, `objects` (декор), `interact` (с `kind`/`item`, как в `quests.json`), `npcs` (id из `npcs.json`). Сервер отдаёт его целиком в чанке `ship 0,0`.
- Качка: вся группа корабля + камера, амплитуда крена ≤ 1,5°, период 6–8 с. Ночью почти 0. Слабее, чем хочется, иначе укачает.
- Два корабля на фоне («Пинта», «Нинья»): та же или меньшая модель, 150–250 м от нас, своя фаза качки. В сцене Канар стоят на якоре в бухте.
- Детали жизни: бочки, канаты, ящики — инстансы из Kenney Pirate Kit.

## F1.5 Остров из чанков — сделано

### Менеджер чанков (`world/chunks.js`)
- Каждые 0,5 с: чанки в радиусе 2 вокруг игрока (5×5); отсутствующие запрашиваем `chunk_req` (ближние первыми, повтор через 3 с), всё вне радиуса прячем.
- **Кеш LRU** с лимитом `cacheLimit` из `auth_ok.world`: при превышении удаляем давно не виденные скрытые чанки, освобождаем геометрию и шлём `chunk_drop`. 5×5 — это ровно 25 = 10% от 257, поэтому запасного кольца нет.
- Проверка: проход через весь остров с запада на восток — в кеше никогда больше 25 чанков (9,7%), 105 запросов, 80 выгрузок.
- `world.stats().chunks` — `{ loaded, total, bytes, totalBytes, pct, limit }` для HUD.

### Построение чанка (`world/island.js`, модели — `world/islandModels.js`)
- Рельеф: сетка 33×33 из `h`; нормали считаются через границу с соседними чанками (без швов), цвет вершин по высоте, уклону и шуму: мокрый песок, пляж, сухая августовская трава, утоптанная земля в городе, кустарник, тёмная порода на склонах, красноватый туф у вершины. Поверх — процедурная текстура деталей.
- Растительность (канарская пальма, драконово дерево, камень, куст) — **по одному `InstancedMesh` на часть модели** для всех видимых чанков: draw calls не растут с числом чанков.
- Постройки по `m`: `house`, `house_governor` (с деревянным балконом), `church` (неф + колокольня), `warehouse`, `market_stall`, `shipyard` (корабль на стапеле), `pier`; интерактивные: `well`, `boat`, `barrel`, `planks`, `tar_bucket`. Побелённые стены, каменные углы и цоколь, черепица. Каждый чанк запекается в несколько мешей.
- Коллайдер на чанк (рельеф + постройки + стволы); в воду можно зайти по пояс, глубже выталкивает на берег.
- **Дорожки** — `paths` в `content/canary_layout.json` (`points`, `width`, `"stone": true` для мощёных). Рисуются шейдером земли попиксельно: площадь, главная улица и улица к церкви вымощены камнем, к домам, хуторам и на вулкан ведут земляные тропы с рваным краем. Сервер по ним же не сажает деревья — после правки дорожек нужен `npm run seed`.
- **Дальний вид острова** (`world/islandLod.js`): весь остров грубо — высоты через 8 м, настоящие модели построек, упрощённые пальмы и драконовы деревья (~20–100 треугольников). Там, где загружен настоящий чанк, LOD убирается. Данные даёт плагин Vite `islandLodPlugin.js` (`virtual:island-lod`) из серверного генератора `server/world/terrain.js` в момент сборки: это ~2% данных мира, правило ≤10% не нарушается, а после правки рельефа всё пересчитывается само. Цена: +19 draw calls и ~25 тыс. треугольников на проход.
- Туман на острове лёгкий (≥ 0,0035): края подгрузки больше нет, остров виден целиком и с моря, и с вершины.
- Замер (Apple M1, Retina во весь экран): город `high` 3,8 мс / 131 draw call, `low` 2,1 мс, `ultra` 13 мс.

## F1.6 Удалённые игроки и NPC (5–6,5 ч, заглушка к 3-му часу)

- Модель персонажа: Quaternius (CC0, с анимациями idle/walk/run/sit). Разные цвета одежды для ролей: юнга — светлое, штурман — синий камзол, переводчик — тёмно-красный.
- **Интерполяция:** буфер снимков, показываем позицию на 100 мс в прошлом; линейная интерполяция позиции и угла.
- Анимации по полю `a` (`idle`/`walk`/`run`/`sit`), переход `crossFadeTo` 0,2 с.
- Табличка с именем и ролью над головой (`CSS2DRenderer` или спрайт), облачко чата — по событию от Фронта 2.
- NPC — те же модели с другими цветами; анимации по сцене (сидят, драят палубу, танцуют вечером). Колумб — отдельная узнаваемая модель/цвет (тёмный плащ, шляпа).
- **К 3-му часу хватит капсулы с именем** — главное, чтобы синхронизация работала.

## F1.7 Звук мира — передан Бэку 2

Всё ниже делает Бэк 2; от мира ему нужны только позиции объектов (`world.entity(id).getWorldPosition()`) и камера (`world.camera`) для `AudioListener`.

- `AudioListener` на камере; разблокировка AudioContext на первом клике (кнопка «Войти»).
- **Фоны по сценам** (зацикленные, плавный переход 2 с):
  - день: волны, ветер в парусах, скрип дерева, чайки (редко);
  - Канары: прибой, птицы, гул рынка у центра (позиционно);
  - вечер: волны, музыка праздника (гитара/бубен, позиционно в круге танцующих), смех;
  - ночь: почти тишина, капли, низкий гул, редкий скрип.
- **Позиционные звуки** (`PositionalAudio`): песочные часы, колодец, очаг кока, фонарь (потрескивание), стуки в борт ночью под палубой, шаги за спинами игроков.
- `audio.play(id, {at})` для событий (выстрел с «Пинты», колокол, удар в борт, крик «Бу!»).
- Голоса NPC проигрывает Фронт 2 (интерфейсный звук), громкость фонов в это время приглушаем на 40%.
- Ночная история: события звука по таймлайну из `content/night_story.json` (`{at: 12.5, sfx: "hull_knock_3"}`).

## F1.8 3D-катсцены (6,5–8 ч)

- **Движок готов** (`world/cutscene.js`). `world.cutscene.play(id, startAt)` → Promise. Камера летит по `CatmullRomCurve3`, взгляд — по второй кривой. Раскадровка, затемнения, полосы, титр, флот, уборка парусов и якорь описаны в `content/cutscenes.json`.
- Каждый кадр считается от `Date.now() − startAt`, поэтому у всех игроков сцена идёт одинаково. Кто подключился поздно, попадает в середину.
- Игра продолжает вызывать `world.frame()`, а катсцена забирает камеру внутри него. На время сцены: чанки грузятся вокруг кадра (`chunks.focus`), другие игроки скрыты, на `body` висит класс `cinematic` (HUD Фронта 2 прячется). Полосы, затемнение и титр рисует сам мир. Угол обзора к концу возвращается к игровому, чтобы передача управления не дёргала зум.
- На тестовой странице сцену запускает клавиша C.
- **`cut_canary` (11 с) — сделано.** Из темноты общий план бухты: флот медленно идёт носом к стоянке далеко от берега, паруса убираются, «Санта-Мария» бросает якорь (брызги), от неё к пристани гребёт шлюпка с двумя матросами. Титр «Ла-Гомера, Канарские острова · Август 1492». Затем пролёт за шлюпкой над пирсом в точку появления.
- **Передача управления без скачка.**
  - В `scenes.json` у `cut_canary` указаны `zone`, `tod` и `spawns`. Сервер ставит игроков на пристань уже в начале сцены, поэтому настоящие чанки у пристани (сервер отдаёт их только рядом с игроком) успевают загрузиться к финальному пролёту.
  - Последний кадр держится, пока камера игры не окажется рядом, но не дольше 2,5 с.
  - Тени на время сцены центрируются по концу текущего плана.
- **`cut_evening` (12 с) — сделано.** Из темноты шлюпка с матросами подходит к борту «Санта-Марии», камера поднимается к реям, паруса разворачиваются. Склейка: флот под парусами идёт на нас, Ла-Гомера остаётся позади, свет золотеет (время 0.52 → 0.68). Затемнение и палуба на закате: гитарист у Старого Хуана, фонари загораются один за другим. В последние 1,4 с камера переходит в глаза каждого игрока.
  - Сервер ставит игроков на палубу в начале сцены (`zone`, `spawns` в `scenes.json`). Остров в первых двух планах — его дальний вид, чанки острова не нужны.
  - Движок для этого научился нескольким вещам: несколько смен зоны за сцену (`switch`), время суток по ключам (`todTrack`), подъём парусов (`furl` ключами), курс кораблей по прямой (`fleet` с `from`/`to`), фонари по очереди (`lamps`), плавный переход в камеру игрока (`blend`; теперь и в `cut_canary`).
- **Гитарист (`musician`, «Матрос Хиль»)** — постоянный NPC на палубе в `ship_layout.json`, сидит на бочонке рядом со Старым Хуаном.
  - Гитара четырёхструнная, как в Испании 1490-х (гитары с пятью и шестью струнами появятся много позже). Руки ставятся по точкам на грифе и розетке (двухзвенная IK), правая перебирает струны.
  - В `npcs.json` он добавлен как `script` с голосом `am_echo`. Реплики и звук гитары — за Бэком 2.
  - Боцман отодвинут от бочки у борта: между ними была щель, где застревал игрок.
- **`cut_night` (25 с):** отъезд от пирующих → корабль целиком на закате → `t` 0.72 → 0.95, туман сгущается, волны стихают, музыка затухает → медленное приближение к фонарю с рассказчиком.
- **`sleep` (10 с):** «веки» (две чёрные плашки сверху и снизу смыкаются) — можно сделать в UI у Фронта 2; ты даёшь затемнение сцены (сердцебиение — Бэк 2).

## F1.9 Оптимизация и проверка (8–10 ч)

- Проверить на **Windows и Linux** в Chrome: `chrome://gpu` → WebGL2 включён, аппаратное ускорение. На слабых — `low`.
- `renderer.info`: draw calls и треугольники в каждой сцене; укладываться в бюджет.
- Выгрузка: `dispose()` геометрий, материалов и текстур выгруженных чанков; проверить, что память не растёт при ходьбе по острову 5 минут.
- Все модели прогнаны через `gltf-transform optimize`.

| Часы | Задача |
|---|---|
| 0,5–1,5 | F1.1–F1.2: рендерер, пресеты, вода, небо |
| 1,5–3 | F1.4: корабль, коллайдер, `collide`/`groundHeight`, фоновые корабли, качка; аватар-капсула для синхронизации |
| 3–5 | F1.5: чанки острова, инстансинг, счётчик % |

| 6,5–8 | F1.8 катсцены |
| 8–10 | F1.9 оптимизация, проверка на трёх ОС |

## Чек-лист готовности
- [ ] День, закат, ночь с туманом выглядят красиво и меняются плавно
- [ ] Корабль с коллизиями, качка, два корабля на фоне
- [ ] Остров подгружается чанками, кеш ≤ 10%, счётчик работает
- [ ] Игроки и NPC с анимациями, плавная интерполяция
- [ ] 4 катсцены синхронно у всех
- [ ] ≥ 50 FPS на всех трёх ноутбуках (с `low` при необходимости)
