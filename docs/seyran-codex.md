# Сейран → Codex на маке

Задачи Сейрана из `docs/tz-sunday.md`, которые надо видеть в игре или проверять на настоящей модели. Поэтому они делаются здесь, на мак-сервере. Логику и тесты без модели делает облачная сессия (`docs/seyran-cloud.md`).

## Как работать

- Ветка `seyran`: `git fetch origin && git checkout seyran && git pull`. Коммитить в неё и пушить: `git push origin seyran`.
- Перед пушем — `git pull --rebase origin seyran`: туда же вливается работа облака.
- **Не трогать сервер на порту 3000** — на нём могут играть. Свой сервер для проверки:
  ```
  npm run build
  PORT=3001 DB_FILE=data/codex.db DEV=1 DEMO=1 node server/index.js
  ```
  Открыть `http://localhost:3001`. Dev-команды в чате игры: `/scene ship_evening`, `/scene night_story`, `/reset`.
- Модель: Ollama должна быть запущена (`ollama serve`), модель `qwen3:4b-instruct`.
- Тесты: `node --test 'client/tests/*.test.js'` и `node --test 'server/tests/*.test.js' 'server/ai/test/*.test.js'`.
- Трогать только файлы из списка ниже. Облако работает в `server/ai/*`, админке и `world-state` — туда не лезть.

## Задачи

### 1. NPC после острова: свои места и маршруты в каждой сцене

Сейчас у NPC в `content/ship_layout.json` один маршрут (`activity`) на всю игру, и он есть только у Колумба. Остальные стоят в одной позе.

- В `shared/npc-activity.js` — маршрут по сцене: `npc.scenes?.[sceneId]` (свои `p`, `r`, `pose`, `activity`), иначе общий. Эта функция работает и на клиенте (`client/src/world/npc-animation.js`), и на сервере (проверка дистанции разговора) — сцену передать в обоих местах.
- **Тамерлан** в этом же файле добавляет паузу маршрута на время разговора. Договориться о формате до начала, сделать одним изменением.
- `ship_day` — как сейчас. `ship_evening` (праздник):
  - Хиль играет на гитаре в центре палубы;
  - матросы у бочки с вином и в круге танца;
  - кок разносит еду;
  - боцман ходит вдоль борта;
  - Колумб у кормы, иногда спускается к людям.

  Маршруты не проходят сквозь мачты, бочки и места игроков.

Готово, когда: `/scene ship_evening` — палуба выглядит как праздник, NPC ходят и занимаются делом. Скриншоты до и после — в PR.

### 2. Рассадка на ночную историю

- `night_story`: Старый Хуан в центре у фонаря. Колумб, боцман, кок, матросы и Хиль сидят вокруг и смотрят на него: поворот считать от позиции рассказчика.
- Места игроков из `content/scenes.json` (`seats`: `[2,1.6,3]`, `[-2,1.6,3]`, `[0,1.6,5]`) не занимать. Круг выглядит общим: игроки сидят в нём же.
- Позы `sit` уже есть в `client/src/world/people.js`.

Готово, когда: `/scene night_story` — круг слушателей, все повернуты к Хуану, никто не сидит в игроке и не висит в воздухе. Скриншот в PR.

### 3. Проверка агентов на настоящей модели (после того как облако вольёт свою часть в `seyran`)

- Подсказки: поговорить с Колумбом 6–8 реплик — кнопки меняются после каждого ответа и подходят к теме.
- Действия: «Адмирал, зажгите фонари», «поднимите флаг», «уберите паруса», «выдайте паёк»; у торговца — «покажи товар». Действие срабатывает, мир меняется у всех игроков (две вкладки).
- Ложные срабатывания: «как дела», «что мне делать», «расскажи про фонари», «хочу кушать» — действий быть не должно.
- Если модель путается — поправить описания действий в `content/agents/*.json` (поле `en`). Логику не переписывать, сообщить в PR облака.
- Прогон: `npm run eval:ai -w server -- columbus` и `-- trader`, время ответа не должно вырасти больше чем на секунду.

Итог — короткий отчёт в описании PR ветки `seyran`: что проверено, где модель ошибается.
