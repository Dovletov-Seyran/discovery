# Выкладка на itch.io

Две версии на одной странице игры:

| Файл | Что это | Как загрузить |
|---|---|---|
| `release/discovery-1492-web.zip` | Одиночная игра прямо в браузере. Игровой сервер работает внутри страницы (`client/src/solo`), сохранения — в `localStorage` браузера, вход только по имени, NPC отвечают заготовленными фразами (без нейросети) | Upload files → отметить **This file will be played in the browser** |
| `release/discovery-1492-multiplayer.zip` | Сервер для игры по сети до 3 человек: собранный клиент, `start-server.command` / `start-server.bat`, `README-multiplayer.txt`. Нужен Node.js 24+ | Upload files → обычный скачиваемый файл (платформы: Windows, macOS, Linux) |

Собрать оба архива:

```bash
npm run release
```

## Настройки страницы (Edit game)

- **Kind of project:** HTML.
- **Embed options:** Viewport 1280 × 720, **Fullscreen button** — включить, **Mobile friendly** — выключить (нужны клавиатура и мышь), Automatically start on page load — выключить (на старте мир строится ~0,5 с и грузится 37 МБ).
- **SharedArrayBuffer** — не нужен.
- **Genre:** Adventure / Educational. **Tags:** history, exploration, 3d, columbus, three-js, singleplayer, multiplayer, lan.
- **Language:** Russian (озвучка NPC — английская, с русскими субтитрами).
- **Inputs:** Keyboard, Mouse.
- **Community:** по желанию — Comments.
- **Visibility:** сначала **Draft** → проверить в браузере по ссылке предпросмотра → **Public**.

## Текст страницы (заготовка)

> **Открытие 1492** — 3D-игра о первом плавании Колумба. Часть первая: юнга, штурман или переводчик на «Санта-Марии» — песочные часы, вода на Канарах, ночные вахты. Часть вторая: тот же 1492 год глазами таино на острове Гуанахани.
>
> **Как играть:** WASD — ходить, тянуть мышью — осматриваться, E — действие, Tab — снаряжение, J — журнал. Прогресс сохраняется в этом браузере.
>
> **Вместе по сети:** скачайте `discovery-1492-multiplayer.zip`, запустите сервер на одном компьютере (нужен Node.js 24+) и откройте адрес в Chrome на остальных — инструкция внутри архива.
>
> Сделано командой из четырёх человек на хакатоне (победа). Код — three.js; модели и текстуры сгенерированы кодом; звуки — Freesound CC0; голоса — Kokoro-82M (Apache 2.0).

## Что проверить перед публикацией

1. Draft-страница открывается в Chrome и Safari/Firefox: экран «Одиночная игра» → имя → роль → «Готов» → интро → корабль.
2. Ctrl+2 / Ctrl+5 (переход к сценам) — остров грузится.
3. Перезагрузить страницу — игра продолжается с того же места.
4. В архиве веб-версии меньше 1000 файлов (скрипт проверяет сам, сейчас ~250).

## Ограничения одиночной версии

- Нейросети нет: NPC отвечают по ключевым словам и кнопкам-подсказкам (`content/agents/<id>.json → script`).
- Сохранение живёт в браузере: другой браузер, приватное окно или очистка данных сайта — новая игра.
- Админки и регистрации нет; «Новая игра» на экране входа стирает прогресс.
