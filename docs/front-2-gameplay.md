# Фронт 2 — вход, управление, взаимодействие, интерфейс, диалоги, мини-игры

**Зона ответственности:** `client/src/net/`, `client/src/game/`, `client/src/ui/`, `client/src/main.js`.
**Общие документы:** [README.md](README.md) (протокол), [content-part1.md](content-part1.md). API мира — в [front-1-world.md](front-1-world.md).

**Цель:** игроку всё понятно без объяснений, интерфейс красивый и не мешает миру.

**Стиль интерфейса:** пергамент и чернила. Панели — полупрозрачная тёмно-коричневая подложка с тонкой золотистой рамкой; заголовки — шрифт с засечками (например, *IM Fell English* или *Cormorant*), текст — читаемый (*Inter*/*PT Sans*). **Шрифты локально** в `public/fonts`. Интерфейс на русском. Всё на HTML/CSS поверх canvas — так быстрее, чем в three.js.

---

## F2.1 Сетевой клиент (`net/socket.js`, 0,5–1 ч)

```js
net.connect(token)          // открыть /ws, первым отправить {t:'auth', token}
net.send(t, payload)
net.on(t, handler)          // подписка на тип сообщения
```
- Переподключение с задержкой 1 → 2 → 5 с, во время переподключения плашка «Связь потеряна…».
- `move` 15 раз/с, только если позиция/поворот/анимация изменились.
- Режим `?offline=1`: заглушка без сервера, чтобы работать до готовности бэка.

## F2.2 Вход и лобби (0,5–2 ч)

- **Экран входа:** название игры «1492», фон — кадр моря/пергамента, поля «Имя» и «Пароль», кнопки «Войти» и «Создать». Ошибки по-русски. Токен в `localStorage`; если он есть — сразу пытаемся войти.
- Клик по «Войти» разблокирует звук (передать Фронту 1).
- **Лобби:** три карточки ролей (картинка, название, строка из content-part1.md §1), занятые — серые с именем игрока. Список игроков с галочками «Готов». Кнопка «Готов».
- Настройки (шестерёнка, Esc): качество `high/low`, громкость (общая, голоса, музыка), чувствительность мыши.

## F2.3 Управление от первого лица (`game/controller.js`, 1,5–3 ч)

- `PointerLockControls`: клик по canvas → захват мыши; Esc → меню.
- WASD, Shift — бег, ходьба 3 м/с, бег 6 м/с, без прыжка.
- Капсула игрока (радиус 0,35, высота 1,7); коллизии через `world.collide`, пол через `world.groundHeight`. Камера на высоте 1,6 м.
- Лёгкое покачивание камеры при ходьбе (bob 2–3 см).
- Управление выключено: в катсценах, в диалоге, в мини-играх, в `night_story` (там можно только вращать головой, с ограничением ±100° по горизонтали).

**Готово (синхронизация 1, час 3):** трое ходят по кораблю, не проходят сквозь борта.

## F2.4 Взаимодействие (`game/interact.js`, 2–3 ч)

- Луч из центра экрана по `world.interactables`, дистанция ≤ 2,5 м.
- Под прицелом — подпись по центру снизу: **«E — Взять астролябию»**, **«E — Говорить с Колумбом»**, **«E — Перевернуть часы»**. Объект слегка подсвечивается (outline или эмиссия).
- Прицел — маленькая точка, на интерактивном объекте превращается в кольцо.
- Нажатие E → сообщение серверу (`pickup`/`interact`/`use`) или открытие диалога/мини-игры. Результат всегда приходит от сервера.

## F2.5 Инвентарь и карточки знаний (3–4,5 ч)

- Панель инвентаря (Tab): 8 ячеек с иконками (рендер иконок заранее или простые SVG).
- **Карточка знаний** при первом подборе предмета: картинка, название, 2–3 строки из `content/items.json` (см. content-part1.md §2). Закрывается по E/клику. Это главный «обучающий» элемент — сделай красиво.
- Внизу справа — быстрая панель с 3 последними предметами.

## F2.6 Задания и HUD (3–4,5 ч)

- **Справа сверху:** текущее задание этого игрока — название и текущий шаг («Наполни бочонок у колодца»), галочки выполненных шагов. Ниже мелко — прогресс партии: «Юнга ✓ · Штурман … · Переводчик ✓».
- **Уведомления** (`notice`) — по центру снизу, 3 с, затухание.
- **Ожидание перехода:** «Ждём остальных: Штурман» (из `party`).
- **F3 — отладочная панель:** FPS, draw calls, `Мир: 23/257 чанков (8.9%) · 118 КБ / 1.4 МБ`, пинг. На защите включаем.

## F2.7 Диалоги с NPC (`ui/dialogue.js`, 4,5–6 ч)

Панель внизу экрана на ~30% высоты:
- Слева портрет NPC (рендер лица или нарисованный), имя («Адмирал Колумб»).
- **Русский текст** реплики (`ru`) с эффектом печатной машинки, скорость подогнана под длительность аудио.
- Маленькой строкой серым — **оригинал** (`en`), по клику разворачивается. Помогает учить английский.
- Аудио `audio` проигрываем сразу, фоновые звуки приглушаем (сказать Фронту 1).
- Пока ждём ответ — «Колумб задумался…» с анимированным многоточием (`npc_thinking`).
- **Поле ввода** «Спросите что-нибудь…» (русский), Enter — отправить.
- **2–3 кнопки-подсказки** (`hints`) над полем ввода; клик → `npc_hint`.
- Для торговца — дополнительные кнопки «Предложить 25 / 30 / 35» и список товаров с текущей ценой и остатком денег.
- Esc или «Прощай» — закрыть.
- Готовые реплики NPC (боцман, кок, плотник) — та же панель без поля ввода, следующая реплика по E.

## F2.8 Чат игроков (5–6 ч)

- Enter → поле ввода внизу слева; последние 6 сообщений, затухают через 10 с.
- Над головой автора — облачко с текстом на 4 с (передать Фронту 1 событие `world.players.bubble(id, text)`).

## F2.9 Мини-игры (6,5–8 ч)

Все — HTML-оверлеи, результат отправляется на сервер (`minigame {game, result}`), сервер решает, засчитывать ли.

| Мини-игра | Как работает | MVP? |
|---|---|---|
| **Песочные часы** | Таймер над часами (кольцо). Когда песок кончился — подсказка, E → анимация переворота + звук песни-молитвы (готовая реплика) | да |
| **Астролябия** | Экран-оверлей с кругом астролябии: мышью вращаешь алидаду, пока Солнце не попадёт в прорезь (показывается угол, цель 73° ± 2°). Затем табличка: «Склонение Солнца 7 августа: +16°. Широта = 90° − высота + склонение» и три варианта ответа: 17°, **33°**, 49°. Неверный ответ — подсказка, ещё попытка | да |
| **Колодец** | Удерживать E 3 с, полоска заполнения | да |
| **Вино** | E у бочки → кружка в руке, 10 с лёгкого покачивания и размытия по краям экрана | да |
| **Танец** | E в круге → 8 с камера покачивается в ритм, звук хлопков | да |
| **Старшая карта** | 2 игрока или игрок против NPC: каждому по карте испанской колоды (oros, copas, espadas, bastos — нарисовать на CSS + символы мастей), у кого старше — выиграл. Подсказка о мастях | если успеем |
| **Армрестлинг** | Быстро жать пробел, полоска силы против NPC | если успеем |

## F2.10 Интро «Книга Марко Поло» (6,5–7,5 ч)

- 6 панелей (тексты в content-part1.md §4.1): полноэкранная картинка с медленным приближением и сдвигом (CSS-анимация), переход растворением 1 с.
- Картинки — стилизованные «пергаментные» иллюстрации. Можно собрать из старинных карт в общественном достоянии (карты XV века, гравюры) + фильтр сепии. Источник и лицензию записать в `docs/credits.md`.
- Голос — готовые файлы `audio/vo/intro_1..6`, субтитры по-русски внизу. Длительность панели = длительность аудио + 0,5 с.
- Кнопка «Пропустить» → `skip_vote`; показывать «Пропустить: 2/3».
- Старт по `startAt` из `scene`, чтобы у всех одновременно.

## F2.11 Титры, субтитры катсцен, сон (7–8 ч)

- Компонент **субтитров** (общий для интро, катсцен и ночной истории): русский текст внизу по центру, тень, до 2 строк.
- **Титры** (по центру, шрифт с засечками, растворение): «Ла-Гомера, Канарские острова. Август 1492» и т.д.
- **Сон:** две чёрные плашки сверху и снизу медленно смыкаются («веки»), 2 раза приоткрываются, затем титр «12 октября 1492 года. 2 часа ночи. — Земля! Земля!» → «Часть 2. Те, кто стоял на берегу».

## F2.12 Ночная сцена и «Бу!» (8–9 ч)

- В `night_story` игрок сидит на месте `seat` (из `scene`), управление только головой.
- Внизу подсказка **«Б — Бу!»** и кольцо перезарядки (20 с).
- Цель — ближайший игрок в секторе ±45° от направления взгляда; если никого нет — кнопка неактивна.
- **У напуганного** (`scared`): громкий крик/вздох, рывок камеры, красная виньетка на 0,5 с, у остальных — смех матросов (готовая реплика).
- Субтитры истории (из `night_story.json`) синхронно с аудио; звуковые события — у Фронта 1.
