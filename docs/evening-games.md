# Вечер: «21 по-морскому» и танец

Основа: актуальный `main`, коммит `745e340`. Внешних библиотек, CDN и облачных API не добавлено.

## Как играть

В сцене `ship_evening` подойти к карточному столу или кругу танцующих и нажать **E**.

- **21:** первый игрок собирает стол и нажимает «Начать» (Enter). До трёх участников против Хуана, три раздачи, 36 карт, без ставок. **H** — ещё карту, **S** — хватит. На ход 20 секунд, затем автоматическое «Хватит». Между раздачами 5 секунд на результат. Победа даёт очко, ничья — ноль. Хуан добирает до 17. Закрытие окна сохраняет место; «Выйти из партии» освобождает его. Поздний посетитель наблюдает до следующей партии.
- **Танец:** после отсчёта 24 подсказки за 20 секунд под вечернюю гитару (72 BPM). Стрелки или **WASD**, попадание в линию оценивается сервером. Ошибки не прерывают танец. Завершение засчитывается независимо от очков; отмена и отключение не засчитываются. Остальные видят шаги, повороты и хлопки весь танец. Для совместного танца нужно свободное место рядом.
- Праздник по-прежнему требует **3 из 4** развлечений. Карты засчитываются после одной завершённой раздачи, танец — после полного исполнения. Клиентское `success: true` не принимается.

## Реализация и изменённые файлы

| Файлы | Что изменено |

| `shared/feast-games.js`, `server/game/cards-engine.js` | Стоимость карт, тузов, исход раздачи, перемешивание, правила Хуана и ритм танца |
| `server/game/feast.js`, `server/db.js` | Серверные сессии, приватные руки/колода, очерёдность, таймеры, переподключение, статистика, сохранение и зачёт |
| `server/ai/feast-commentary.js` | Короткие фоновые реплики местной модели с личностью Хуана; только публичные события и статистика завершённых раздач; немедленная резервная реплика |
| `server/game/index.js`, `rules.js`, `entities.js`, `director.js`, `player-actions.js`, `shared/protocol.js` | WebSocket, занятость Хуана, блокировка движения во время танца, ограниченное ожидание активностей перед переходом сцены |
| `client/src/ui/feast-games.js`, `style.css`, `client/src/main.js`, `ui/scene-progress.js` | Карточный стол, таймеры, наблюдение, ритмическая игра, клавиатура, управление курсором, адаптация узкого окна |
| `client/src/world/dance-pose.js`, `people.js`, `game/remote-equipment.js`, `audio/world-audio.js` | Общая анимация танца и синхронизация с гитарой; предмет в руке временно скрывается и возвращается |
| `content/quests.json`, `content/ship_layout.json` | Названия объектов и подтверждённые сервером условия квеста |
| `server/tests/feast.test.js`, `server/tests/gameplay.test.js`, `server/ai/test/feast-commentary.test.js`, `client/tests/feast-games.test.js`, `server/scripts/smoke.js` | Проверки правил, приватности, повторных/чужих ходов, восстановления, отмены, таймеров, ИИ, анимации и интерфейса |

Закрытая колода хранится в отдельной таблице SQLite `minigame_state`, не в публичном снимке мира. Модель не получает закрытых карт. ИИ не задерживает игру: запросы короткие, с низким приоритетом и ограничением частоты 12 секунд. Карточная партия ограничена 210 секундами, сбор игроков — 60. Обычные разговоры, предметы и прежние анимации сохранены.

## Проверки

- Полный набор: `node --test server/tests/*.test.js server/ai/test/*.test.js client/tests/*.test.js` — **245 проверок: 244 прошли, 1 пропущена, ошибок нет**.
- Сборка: `npm run build -w client -- --outDir /tmp/discovery-feast-dist` — успешно. Остаётся предупреждение Vite о крупных чанках.
- Два авторизованных клиента на отдельном HTTP-сервере: три раздачи, 12 проверок скрытых рук, переподключение с восстановлением места и руки, серверный зачёт карт — успешно.
- В браузере проверены стол с двумя игроками, запуск танца через E, подсказки направлений, полный отсчёт и результат с зачётом задания даже при нулевом счёте. Снимки: `docs/screenshots/evening-games/`.
- Проверена очистка сессий при смене сцены, выходе и отключении; личный разговор с Хуаном исключает одновременный захват стола; стол освобождает Хуана по окончании/выходу/тайм-ауту.

## Запуск

Обычный запуск: `npm run build`, затем `npm start` (или существующий HTTPS-запуск проекта). Нужна вечерняя сцена. Локальная Ollama используется через существующую конфигурацию; `AI=0` включает резервные реплики.

Изолированная проверка без изменения основной базы и сборки:

```sh
npm run build -w client -- --outDir /tmp/discovery-feast-dist
PORT=3001 DB_FILE=data/feast-test.db CLIENT_DIST=/tmp/discovery-feast-dist AI=0 TTS=0 DEV=1 DEMO=1 npm start
```

Для полного сетевого smoke-теста указать **отдельный тестовый сервер**: `SERVER=http://localhost:3001 npm run smoke`. Он выполняет `/reset`, поэтому не запускать его на игровой базе.

Ограничения: карточные комментарии текстовые; денежные ставки отсутствуют; отключение отменяет танец. Задержка LAN учитывается общими часами, но попадания оцениваются по времени получения на сервере. Основной игровой сервер и GitHub этой работой не обновляются автоматически.
