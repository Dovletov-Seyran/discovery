# Канары: локальная доработка

База: свежий main `731e0ea` (включая вечерние игры). Ветка `sanjar`, без пуша.

## Передвижение и производительность

Фоновые жители и наземные животные раньше соединяли точки маршрутов прямыми, проходящими через здания. Теперь при создании населения строится небольшой граф видимости с обходом повёрнутых домов, склада, губернаторского дома и церкви с башней. Проходы между точками и замыкание маршрутов проверяются. При реакциях на игроков точка дополнительно выталкивается из расширенного контура здания. Пути вычисляются один раз, по кадрам нет поиска пути и дополнительных запросов к серверу; инстансинг и ограничения дальних анимаций сохранены. Увеличение FPS не заявляется: отдельный замер на слабом ноутбуке ещё нужен.

Регрессионный тест проверяет четыре стены каждого реального дома, фермы, склада и дома губернатора с учётом поворота. Коллайдеры игроков уже присутствовали и этот тест проходят; менять их на сплошные коробки и блокировать входы не потребовалось. Полный длительный скан острова из dev/physics-test.mjs остановлен; он не считается завершённой проверкой всех точек рельефа.

## Механики

- Колодец: 3,5 секунды работы рядом. До завершения пустой бочонок остаётся в инвентаре. Отход, отключение или смена запуска сцены отменяют работу. После завершения сервер заменяет его наполненным и засчитывает шаг существующего задания.
- Ремонт: последний материал для плотника передаётся после 3 секунд совместной работы. Только после этого завершается существующее задание ремонта. При отмене материал остаётся у игрока, повторное начало не создаёт дубликат работы.
- Клиент показывает неблокирующую полосу работы. Анимация предмета и рук видна другим игрокам через существующий player_action; локальные звуки воды и работы по дереву синтезируются Web Audio без загрузки файлов. Событие island_activity содержит статус, название, длительность и серверное время; передача по кадрам не нужна.
- Торговля: изображения товаров и счётчик купленных припасов, подсказка возврата после завершения закупки; существующая экономика и ИИ-торг не изменены.
- Необязательное задание «Гомера перед отплытием»: три читаемых стенда возле колодца, рынка и верфи. Порядок любой, краткие заметки сохраняются в состоянии задания и доступны в журнале J после ухода с острова. Обязательный переход к шлюпке не требует их чтения.
- Исправлена обнаруженная по журналу действующего сервера ошибка present(): расписание NPC является объектом scenes, а ограничение присутствия — массивом. Взаимодействия с персонажами больше не вызывают scenes.includes is not a function.

## Проверки и запуск

275 тестов прошли, один пропущен. Production-сборка успешна. Проверены детерминированные обходы зданий, стены и повороты, отмена/повтор работы, серверное наполнение бочонка, ремонт и списание материалов, чтение в любом порядке и сохранение исследования, взаимодействие с NPC с объектным расписанием. Общие проверки кеша, инстансинга, существующих заданий и второй части также проходят.

Сервер просмотра: порт 3102, DEV=1, AI=0, прежняя БД work/gameplay-review.db без сброса аккаунтов и прогресса. Сервер перезапущен на новой сборке. Автоматическая визуальная проверка не завершена: встроенный браузер открывался нестабильно; фактическое расположение интерфейса, громкость звуков и удобство маршрутов требуется оценить в игре.
